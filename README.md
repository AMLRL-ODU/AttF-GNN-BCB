AttF-GNN has been trained on four datasets: BRCA, GBM, ROSMAP, and PRAD. The repository has three files:

1. Code for feature selection
2. The main framework code
3. Supplementary file containing results that were not presented in the main paper.

To run this:

1. Authors have utilized Pytorch Geometric
2. LSTM aggregator from PyG
3. MI and ANOVA.
